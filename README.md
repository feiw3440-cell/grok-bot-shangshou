# Grok Bot 上手 · 五天操作手册

![系列](https://img.shields.io/badge/系列-第%201–5%20天合集-blue) ![Lang](https://img.shields.io/badge/提示词-中文%20%2F%20English-2ea44f)

这是「Grok Bot 上手」系列的合集仓库：五天五篇操作手册，按顺序读下来，可以从给 Bot 办入职，走到晨报、回信与排会议、专职店长，再到群组协作。

本系列已经完结，没有第 6 天。

## 目录

| 篇 | 手册 | 这一天练什么 |
| --- | --- | --- |
| 第 1 天 | [入职说明与检查清单](day1-checklist/README.md) | 装好之后第一天最该做的不是聊天，是给它办入职：写清岗位和边界，派一件能验收的小任务，再按四个等级放权。 |
| 第 2 天 | [每日晨报](day2-morning-briefing/README.md) | 让它每天早上主动发一份有用的五栏晨报，并把这件事做成例行任务。 |
| 第 3 天 | [回信与排会议](day3-reply-and-calendar/README.md) | 让它起草回信、查空档、按你选定的时间写入日历；发出去的权利仍是你的。 |
| 第 4 天 | [专职店长](day4-shop-manager/README.md) | 当店务有了独立来源、边界和节奏，请一位专职店长，而不是继续给总管加活。 |
| 第 5 天 | [群组协作](day5-group-collaboration/README.md) | 把总管和店长放进同一个群，做一次看得见的只读协作。这是系列收官。 |

每篇都是可以照着走的手册：前置条件、步骤、提示词模板（中 / 英）和验收清单。配图为自制示意图和已打码的界面截图。
